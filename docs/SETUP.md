# Setting up RoboSketch on a new computer

About 15 minutes to run the app in a browser. Running it on a phone with Bluetooth adds a
one-time native build (30–60 minutes the first time, mostly downloads).

Copy commands one line at a time, or a whole block without the `#` lines: on macOS, zsh treats
pasted `#` lines as commands.

## 0. Get access

The project owner adds you on GitHub: **MeetM0/RoboSketchx → Settings → Collaborators → Add
people**. Accept the invitation email, then sign in to GitHub on your computer (Git asks the
first time you clone).

## 1. Install the tools

You need **Git**, **Node.js 22 LTS** (20.19.4 is the minimum) and **Chrome or Edge** (the
browsers with Bluetooth).

| System | Install |
| --- | --- |
| macOS | Git: `xcode-select --install`. Node: the macOS installer for 22 LTS from [nodejs.org](https://nodejs.org) |
| Windows | `winget install Git.Git` then `winget install OpenJS.NodeJS.LTS` (or the installers from git-scm.com and nodejs.org) |
| Linux | Git from your package manager. Node with [nvm](https://github.com/nvm-sh/nvm): `nvm install 22` |

Already use nvm? Inside the project folder, `nvm use` picks the version in `.nvmrc`.

Open a **new** terminal and check:

```
git --version
node -v
```

`node -v` must print `v20.19.4` or newer (`v22.x` recommended).

## 2. Get the code

```
git clone https://github.com/MeetM0/RoboSketchx.git
cd RoboSketchx
```

The main branch is `master`.

## 3. Install and verify

```
npm run setup
```

This checks your Node version, installs the exact dependency versions from
`package-lock.json` (`npm ci`), then runs the type check and the tests. It ends with
`✔ RoboSketch is set up.` If it stops with an error, see Troubleshooting below.

## 4. Run it in the browser

```
npx expo start --web
```

The app opens at http://localhost:8081. Press `Ctrl+C` in the terminal to stop it.
Bluetooth to the robot works in Chrome and Edge, not Safari or Firefox.

## 5. Run it on a phone

### Quick look, no Bluetooth: Expo Go

Install **Expo Go** from the App Store or Play Store, put the phone on the same Wi-Fi as the
computer, run `npx expo start --go` and scan the QR code. Everything works except connecting
to the robot. Expo Go only runs projects on the Expo SDK version it currently supports; if it
says this project (SDK 54) is incompatible, use a development build instead.

### With Bluetooth: a development build

The Bluetooth library is native code that Expo Go doesn't include, so build the app once onto
the phone over USB.

**iPhone (needs a Mac):**

1. Install Xcode from the App Store, open it once and accept the licence.
2. Install CocoaPods: `brew install cocoapods` (or `sudo gem install cocoapods`).
3. On the iPhone: Settings → Privacy & Security → **Developer Mode** on, then restart.
4. Plug the phone in and run:

   ```
   npx expo run:ios --device
   ```

   The first run asks for an iOS bundle identifier: enter one unique to you, such as
   `com.yourname.robosketch`. Each person uses their own, because an identifier registered
   to one Apple account can't be reused by another.

5. If it asks for a signing team: open `ios/RoboSketch.xcworkspace` in Xcode, select the
   RoboSketch target → Signing & Capabilities, choose your Apple ID team, then run the
   command again.
6. If the phone says "Untrusted Developer": Settings → General → VPN & Device Management →
   trust your Apple ID.

**Android (Mac, Windows or Linux):**

1. Install Android Studio. In its SDK Manager, install the Android SDK and Platform-Tools.
2. Set `ANDROID_HOME` to the SDK folder (shown in the SDK Manager) and add its
   `platform-tools` folder to your PATH.
3. On the phone: Settings → About phone → tap **Build number** 7 times, then Developer options
   → **USB debugging** on.
4. Plug the phone in, accept the debugging prompt, and run:

   ```
   npx expo run:android --device
   ```

   The first run asks for an Android package name; enter one such as `com.yourname.robosketch`.

After the first build, start the app day to day with `npx expo start --dev-client` and open
RoboSketch on the phone. Rebuild with `run:ios` / `run:android` only when native packages
change.

The `ios/` and `android/` folders are generated by these commands and are not committed.

## 6. Day-to-day workflow

```
git checkout master
git pull
npm ci
git checkout -b your-name/short-description
```

- Run `npm ci` after every pull that changed `package-lock.json`. It installs exactly what is
  locked and never rewrites the file.
- Before pushing, run `npm run check` (type check, lint and tests).
- Add packages with `npx expo install <package>` so the version matches Expo SDK 54, and
  commit `package.json` and `package-lock.json` together. Don't commit lockfile changes you
  didn't intend.
- Open a pull request into `master`; don't push to `master` directly.

## Troubleshooting

| What you see | Fix |
| --- | --- |
| `git pull`: *Your local changes to package-lock.json would be overwritten* | `git checkout -- package-lock.json`, then `git pull`, then `npm ci` |
| The browser shows the default Expo welcome screen | You're on old code: `git checkout master`, `git pull`, `npm ci` |
| `PluginError` mentioning `react-native-ble-plx`, or *Cannot find module* | Dependencies are missing: `npm ci` |
| `npm ci`: *package.json and package-lock.json are not in sync* | `git checkout -- package.json package-lock.json`, `git pull`, `npm ci` |
| `EBADENGINE` or *Unsupported engine* | Node is too old: install Node 22 LTS (step 1) and open a new terminal |
| `zsh: command not found: #` | You pasted a comment line; paste only the command lines |
| **Connect robot** shows an error in the browser | Use Chrome or Edge; Safari and Firefox have no Web Bluetooth |
| **Connect robot** says Bluetooth isn't available, on a phone | You're in Expo Go: make a development build (step 5) |
| *Port 8081 is being used* | Another Expo is running: stop it, or `npx expo start --web --port 8082` |
| Odd errors after switching branches | `npx expo start --web --clear` |
