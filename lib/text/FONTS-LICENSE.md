# Font licences

`lib/text/font-data.ts` is generated by `scripts/build-fonts.js` from the SVG fonts in the
[`hersheytext`](https://www.npmjs.com/package/hersheytext) package (MIT). The glyph data keeps
the licences of the original fonts, reproduced below.

| Style | Font | Licence |
| --- | --- | --- |
| Print | EMS Readability | SIL Open Font License 1.1 |
| Handwriting | EMS Felix | SIL Open Font License 1.1 |
| Cursive | Hershey Script 1-stroke | Hershey Fonts licence (below) |
| Calligraphy | EMS Allure | SIL Open Font License 1.1 |

The EMS fonts were created by Sheldon B. Michaels, with SVG font conversion by Windell H. Oskay
(Evil Mad Scientist Laboratories). The full text of the SIL Open Font License is at
https://openfontlicense.org.
